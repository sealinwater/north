# North • Cloudstream 3 Extension Repository (`sealinwater/north`)

**North** is a Deep Blue Nordic & Danish Movies & TV Series extension for Cloudstream 3, featuring a pre-roll **NORTH** studio intro, seekable MKV/MP4 torrent streaming, real-time Chromecast stereo AAC audio transcoding, validated TheIntroDB/IntroDB skip buttons, and Ghost Ratio protection.

> ⚠️ **ACCOUNT API KEY REQUIRED:**  
> North connects to the private **NordicBytes** tracker (`https://nordicbytes.org`). **An active NordicBytes account and personal UNIT3D API Key are required to make this extension work.**

---

## 🔑 How to Sign Up & Get Your API Key

### Step 1: Apply for an Account at [`https://nordicbytes.org/application`](https://nordicbytes.org/application)

If you do not already have a NordicBytes account, submit an application at **[https://nordicbytes.org/application](https://nordicbytes.org/application)**:

1. **Your Application is Public (`Your application` & `Your experience with private trackers`):**
   - Everything you write in your application text and your experience level (e.g., *"New — I haven’t used private trackers before"* or experienced) is **visible to every member of the community**.
   - Community members read your application to decide whether to vouch for you. Be honest, be specific, and make it count.
   - ⚠️ **Do NOT, under any circumstance, include your real name, home address, or any other personal identifiable information (PII).**
2. **Where Are You From? (`Anonymous`):**
   - Optional — shown to the community alongside your application.
3. **Email Address (`Staff only`):**
   - Visible **only to staff**.
4. **Tracker Proofs (`Staff only` — Required):**
   - Provide **at least 2 screenshots** (`Screenshot URL` + `Profile URL`) showing your tracker membership — username, ratio, and upload/download stats.
   - *Required; no proof = automatic rejection.*

### Step 2: Generate / Copy Your API Key

1. Once your account is approved, log in at **[https://nordicbytes.org/login](https://nordicbytes.org/login)**.
2. Click your **Profile Avatar (top right) → Settings → API Key / Security** (`API Token`).
3. Copy your personal **UNIT3D API Token**.

### Step 3: Add Your API Key in Cloudstream

1. In Cloudstream, go to **Settings → Extensions** and tap the **⚙️ Gear Icon** next to **North**.
2. Paste your token into **North (NordicBytes) API Key**.
3. Tap **✓ Save & Restart CloudStream** *(or type `apikey:YOUR_TOKEN` directly in the Cloudstream search bar)*.
