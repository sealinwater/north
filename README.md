**North** is a Deep Blue Cloudstream 3 extension designed for private Nordic tracker integration (`sealinwater/north`).

## 🚀 How to Install in Cloudstream 3

1. Open **Cloudstream 3**
2. Go to **Settings ➜ Extensions ➜ Add Repository**
3. Paste the **`py.md`** Short URL or direct GitHub Repository URL:
   - **`py.md` Short URL:** `https://py.md/pwahR` (or shortcode `!pwahR` / `!north`)
   - **Direct GitHub Repo URL:** `https://raw.githubusercontent.com/sealinwater/north/builds/repo.json`

---

## ✨ Features

- **100% Freeleech & 2x Double Upload Priority:** Built-in ratio builder modes to keep your tracker ratio healthy.
- **Full Season Pack Episode Selector:** Automatically expands season packs into individual episode streams mapped via `#index=N` to TorrServer.
- **ExoPlayer Compatibility Priority:** Ranks fast-playing `1080p`/`WEB-DL` streams ahead of heavy 50GB Blu-ray Remuxes.
- **Playback & Language Preferences:** Configurable Auto-Skip Intros, Skip Resume Prompt, and Language Priority (Danish, Nordic Multi, English).
- **Worry-Free 48h Auto-Seed Bridge:** Automatically forwards played magnet/torrent links to your qBittorrent WebUI, Seedbox, or Discord/Autobrr Webhook.
